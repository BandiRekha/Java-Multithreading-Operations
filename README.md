# Java Multithreading Operations

This project demonstrates multithreading in Java using the Runnable interface.

## Operations Included
- Addition
- Subtraction
- Multiplication
- Printing with delay

## Concepts Used
- Thread class
- Runnable interface
- Thread.sleep()
- Concurrent execution

## How to Run
1. Compile the program:
   javac Program_3.java

2. Run the program:
   java Program_3
